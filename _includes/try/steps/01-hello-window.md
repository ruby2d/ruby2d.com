# Hello, window

Welcome! Over the next half hour or so, you'll learn how Ruby 2D works by drawing things, moving them around, and eventually building a tiny game. Everything happens right here: edit the code, press **Run** (or ⌘Enter / Ctrl+Enter), and watch the window.

The program below is a complete Ruby 2D app. `set` paints the background, `Square.new` draws a square, and `show` opens the window. Every app you'll write has this same rhythm: describe what you want, then `show` it.

**Try this:** change `'navy'` to `'teal'`, `'purple'`, or `'olive'`, then run it. The square would like a new color too.
